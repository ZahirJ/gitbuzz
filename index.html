How to solo with the box

      About 25 minutes, done in order
    

    

    

    

      If you get lost while the song plays
      
Don't stop. Let a bar go by, find the nearest red-ringed home note, and start a new short phrase from it. If a note sounds wrong, slide it one fret up or down; one of the two will fit. No note in the box is ever far from a good one.

        Position (box)
        

      

      
A box is one hand position, about 4–5 frets wide, with 2 notes per string. Learn Box 1 first, then connect it to its neighbours until the whole neck joins up.
